# Домашнє завдання 40 — React під контролем: від стану до запитів

## Завдання

- Створити **контрольований компонент** — форму з текстовим полем, чекбоксом і випадаючим списком (select), значення яких зберігаються у стані React.
- Під час відправки форми надіслати дані POST-запитом (`fetch`) на `https://jsonplaceholder.typicode.com/posts` і показати відповідь сервера.
- Обробити стани завантаження та помилки.

## Реалізація

- `src/components/FeedbackForm.jsx` — контрольована форма (ім'я, повідомлення, тема, підписка) з валідацією, показом поточного стану форми, станами `loading` / `success` / `error` та POST-запитом через `fetch`.
- `src/components/ResponseView.jsx` — відображення відповіді сервера.
- `src/components/UncontrolledForm.jsx` — для порівняння: неконтрольоване поле, значення якого читається через `useRef`.

## Запуск

```bash
npm install && npm run dev
```

Інші команди: `npm run build` — збірка, `npm run lint` — перевірка ESLint, `npm run preview` — перегляд збірки.
