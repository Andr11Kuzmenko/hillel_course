# Домашнє завдання 39 — Компоненти React: Stateful проти Stateless

## Завдання

- Створити **Stateful**-компонент, який використовує `useState` для зберігання та зміни стану.
- Створити **Stateless**-компонент, який отримує дані через props і лише відображає їх.
- Stateful-компонент передає дані stateless-компоненту через props.

## Реалізація

| Компонент | Тип | Опис |
|---|---|---|
| `TaskList` | Stateful | Список задач: додавання, позначення виконаною, видалення, очищення виконаних |
| `TaskItem` | Stateless | Відображає одну задачу, викликає обробники з props |
| `TaskStats` | Stateless | Показує статистику виконання та прогрес-бар |
| `Counter` | Stateful | Лічильник зі змінним кроком |
| `CounterDisplay` | Stateless | Відображає значення лічильника |

## Запуск

```bash
npm install && npm run dev
```

Інші команди: `npm run build` — збірка, `npm run lint` — перевірка ESLint, `npm run preview` — перегляд збірки.
