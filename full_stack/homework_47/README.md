# Homework 47 — Веб-форма з використанням Formik та Yup

## Завдання

Розробити веб-форму з валідацією, використовуючи **Formik + Yup** (або React Hook Form).
Обрано Formik + Yup.

## Реалізація

Форма реєстрації (`src/components/Form.jsx`) з полями:
ім'я, email, пароль, підтвердження пароля, вік, телефон, стать (select), згода з умовами (checkbox).

- `src/validationSchema.js` — Yup-схема з повідомленнями українською:
  - ім'я — 2–50 символів, лише літери / пробіл / дефіс / апостроф;
  - email — коректний формат;
  - пароль — ≥ 8 символів, мала та велика латинські літери, цифра;
  - підтвердження — `oneOf([Yup.ref('password')])`;
  - вік — ціле число 18–120;
  - телефон — формат `+380XXXXXXXXX`;
  - стать — одне зі значень списку;
  - згода — обов'язково `true`.
- `src/components/FormField.jsx` — обгортка над `Field` + `ErrorMessage`; помилка й червона рамка
  показуються лише для полів, яких торкнувся користувач (`touched`), валідні поля підсвічуються зеленим.
- Кнопка «Зареєструватися» неактивна, поки форма невалідна, не змінена або відправляється
  (`isValid`, `dirty`, `isSubmitting`); кнопка «Очистити» скидає форму.
- Відправлення імітує запит (1 с), після чого під формою показуються надіслані дані
  (`src/components/SubmittedData.jsx`, пароль замасковано), а форма скидається (`resetForm`).

## Запуск

```bash
npm run build    # продакшн-збірка у dist/
npm run preview  # перегляд збірки
npm run lint     # перевірка ESLint
```
