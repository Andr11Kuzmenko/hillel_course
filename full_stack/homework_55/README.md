# HW 55. Асинхронна робота з файлами в Node.js

## Завдання

Використовуючи модуль `fs/promises` та `async/await`, реалізувати набір асинхронних функцій для роботи з файловою системою
з обробкою помилок через `try/catch`:

- створення директорії (`mkdir` з `recursive`), перевірка існування (`access`);
- створення, запис, дописування та читання файлів (`writeFile`, `appendFile`, `readFile`);
- копіювання (`copyFile`), перейменування (`rename`), видалення (`unlink`, `rm`);
- отримання інформації про файл (`stat`) та вмісту директорії (`readdir`);
- паралельне виконання операцій через `Promise.all`.

Функції — у `fileManager.js`. `index.js` виконує повний сценарій у тимчасовій папці `tmp-sandbox/`,
демонструє перехоплення помилок (`ENOENT`, `EEXIST`) і в блоці `finally` видаляє тимчасову папку.

## Запуск

```bash
cd full_stack/homework_55
npm start
```

Залежностей немає — потрібен лише Node.js 18+.
