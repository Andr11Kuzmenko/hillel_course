Gulp Build Pipeline

SCSS → Autoprefixer → CSS → minified bundle, with BrowserSync live reload.

See features

What this build does

  • SCSS compilation

    Source SCSS in src/scss/ is compiled with Dart Sass.

  • Vendor prefixes

    Autoprefixer adds the right vendor prefixes based on Browserslist.

  • Readable + minified output

    Generates both main.css (expanded) and main.min.css (minified).

  • Live reload

    BrowserSync watches sources and reloads the page automatically.
